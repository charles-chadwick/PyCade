# PyCade
<hr>
This is a simple recreation of some classic arcade games. 


### AI Usage
<hr />
The whole point of developing this program was to learn Python, and re-establish the connection I used to have learning and writing code. In the last few years, I've been leaning heavily on AI professionally, and it sucked all the fun out of development. So this is my attempt to get back to what I used to love. 

All that said, I have decided to use Claude Code in small doses. It should be a tool, not a solution. Here is how I've leveraged it for this project. 

- **Git Commit Messages**: AI can come up with far more concise commit messages. 
- **Basic Refactoring**: When I need things moved around. PyCharm is great for this, but Claude is more thorough.
- **Bugs I Can't Figure Out**: There have been a few instances where I've asked Claude why something isn't working the way I want it to. 
- **Suggestions**: Along with the above item, I've had Claude help optimize certain things. An example of this is in `players.checkForCollisions()`. Claude made it better.
